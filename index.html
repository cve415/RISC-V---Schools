BOOM — Berkeley Out-of-Order Machine

Superscalar, out-of-order RISC-V processor written in Chisel. Originally a graduate research project, now widely used as a teaching platform for advanced microarchitecture study.

Microarchitecture UC Berkeley
github.com/riscv-boom/riscv-boom ↗

CVA6 (Ariane)

64-bit, application-class RISC-V core capable of booting Linux. Developed at ETH Zürich's PULP Lab and now a widely adopted open-source reference for out-of-order execution research.

Application Core ETH Zürich
github.com/openhwgroup/cva6 ↗

Ibex

Small, 32-bit RISC-V microcontroller core (RV32IMC) for energy-constrained embedded systems. Originated from ETH Zürich's zero-riscy project, now maintained under lowRISC.

Embedded / MCU ETH Zürich / lowRISC
github.com/lowRISC/ibex ↗

SHAKTI Processor Family

India's first indigenous RISC-V processor family, developed entirely by students and researchers at IIT Madras. Spans embedded C-class cores through high-performance E-class server designs.

Processor Family IIT Madras
shakti.org.in ↗

BRISC-V

Modular, open-source RISC-V design space exploration platform built at Brown University. Supports single-cycle, multi-cycle, and pipelined core configurations for architecture coursework.

Design Space Exploration Brown University
github.com/yschiebelhut/BRISC-V ↗

OpenPiton + Ariane

Many-core research platform integrating the Ariane RISC-V core into Princeton's OpenPiton framework, enabling scalable multi-core architecture research across dozens of tiles.

Many-Core Research Princeton / ETH Zürich
github.com/PrincetonUniversity/openpiton ↗

Rocket Chip Generator

Parameterizable RISC-V SoC generator written in Chisel, originally produced by UC Berkeley students. Underpins much of the commercial and academic RISC-V ecosystem as a foundational reference design.

SoC Generator UC Berkeley
github.com/chipsalliance/rocket-chip ↗

XiangShan (香山)

High-performance, open-source RISC-V processor developed by students at the Institute of Computing Technology, Chinese Academy of Sciences. Targets server-class performance with aggressive out-of-order pipelines.

High-Performance ICT / CAS China
github.com/OpenXiangShan/XiangShan ↗
